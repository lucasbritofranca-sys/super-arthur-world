# ADR-002: Difficulty-specific Game Over and downward-only difficulty changes

## Status
Accepted

## Date
2026-10-11

## Context
The user chose Easy, Classic and Hard with different lives, time, damage, enemies and checkpoints. The latest answer explicitly corrected the Classic penalty: lose current-world progress, not merely return to its first level.

## Decision
Ordinary death consumes one life and resumes from an eligible checkpoint. Game Over in Easy resets the current level; Classic resets the current world to its first-arrival progression; Hard resets the entire active campaign. Other save slots are unaffected. All difficulties have checkpoints with decreasing density. Difficulty may be lowered on the map; increasing requires a new campaign.

## Alternatives Considered
### Preserve all campaign progress in every mode
Simple and forgiving but explicitly rejected.
### Classic returns to the world's first level without erasing progress
An earlier answer selected this; the user's later correction supersedes it.
### Remove checkpoints in Hard
Explicitly rejected in favor of checkpoints in every difficulty.

## Consequences
### Positive
Each difficulty has a consequential and explainable penalty.
### Negative
Reset behavior must account for collectibles, exits, shortcuts, boss state and remote saves.
### Risks
A reset can be undone accidentally by stale synchronization or a save callback. Treat resets as new authoritative campaign state; surface actual divergent versions without silently merging progress.

## Implementation Notes
The PRD defines observable reset boundaries. Versioning and persistence contracts belong to the Techspec.
